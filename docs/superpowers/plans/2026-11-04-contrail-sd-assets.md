# Contrail 5a — SD Card, Logos and Aircraft Shapes Implementation Plan

> **Superseded in part (2026-11-04).** This plan is kept as written. Where it differs from the spec's *As built* notes (`docs/superpowers/specs/2026-11-04-contrail-sd-assets-design.md`), the spec wins: in particular Task 14's `Esp32Storage` on the Arduino `SD` library (`SD.begin`, FATFS) was replaced by our own read-only stack (`SdSpi` + `FatReader`, spec §2a).

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every flight shows its airline's real logo (from `logos.pak` on an SD card) or a drawn tail fin, and an aircraft shape that matches its type, on Closest Flight, the Board, the Alert, the Radar and the Map.

**Architecture:** Aircraft shapes (12 families, top and side views) and the type → family table are generated by a Python tool into a committed C++ file and drawn with `aaPolygon`. Tail fins are drawn vectors. Real logos are palette images pre-scaled by `build_pack.py` into one pack file; the firmware reads it through a small `IStorage`/`IFile` HAL (SD on VSPI on the ESP32, a folder on the desktop), into the screen arena, and draws it with `drawBadge`.

**Tech Stack:** C++17 on ESP32 (Arduino, LovyanGFX) and native; PlatformIO; Unity tests with golden PPMs; Python 3 + Pillow (`tools/.venv`) for the tools.

**Spec:** `docs/superpowers/specs/2026-11-04-contrail-sd-assets-design.md`. Mockups: `logos-canvas` (private canvas).

**Decisions made while planning** (small; record them in the spec at the end, Task 15):
- The type table holds *every* Doc 8643 type (2,788 × 4 B ≈ 11 KB), not only jets: the firmware cannot apply the class rules (`L2P` → light twin …) without knowing each type's class, so the generator applies them and stores the result. Still well inside the 45 KB budget.
- Each logo size block carries its own CRC-16 (instead of one CRC per item), so loading a 25 px Board badge reads ~400 B, not the whole 3.7 KB item.
- Radar and Map icon sizes come from the family's typical wake class (as on the canvas): light single, light twin, business jet, helicopter 13 px; narrowbody, regional, turboprop, fast jet 16; widebody, jumbo, airlifter 20; superjumbo 22.
- Only Cinematic Closest puts a badge beside the callsign; Bold Editorial puts its 30 px badge in the band before the airline name (as the mockups).

```python
#!/usr/bin/env python3
"""Build firmware/lib/core/data/ShapeData.cpp: the aircraft shape families and the type table.

The 12 families' outlines come from tools/shapes_outlines.json (drawn on the 5a canvas) and are
stored as uint8 half-units. Every ICAO Doc 8643 type in tar1090-db's icao_aircraft_types2.js
(gzipped JSON: {"B789": ["BOEING 787-9 Dreamliner", "L2J", "H"], ...}) is classified into a family
by rule (description class, wake category, name keywords) with tools/shapes_overrides.csv on top,
and stored as a sorted uint32: the code in base 37 (21 bits) << 4 | family (1..12).

  curl -L -o types.js.gz https://raw.githubusercontent.com/wiedehopf/tar1090-db/2ab834a65f2fbde9457823e88682cd46954b8bc1/db/icao_aircraft_types2.js
  python3 -I tools/gen_shapes.py --types types.js.gz --out firmware/lib/core/data/ShapeData.cpp
  python3 -I tools/gen_shapes.py --selftest

Exit codes: 0 written, 2 jets left unclassified (listed; add them to the overrides), 3 a known type
came out wrong. The output is committed, so firmware builds never need this script or the data.

def has(name, words):
    return any(w in name for w in words)


def classify(code, name, desc, wake):
    """The family for one type, or None for a jet the rules cannot place."""
    kind = desc[:1]
    engines = desc[1:2]
    power = desc[2:3]
    if kind in "HT":  # helicopters and tilt-rotors
        return "helicopter"
    if power == "J":
        if has(name, SUPERJUMBO):
            return "superjumbo"
        if has(name, AIRLIFTER):
            return "airlifter"
        if has(name, FASTJET_MAKERS):
            return "fastjet"
        if has(name, BIZJET):
            return "bizjet"
        if has(name, REGIONAL):
            return "regional"
        if engines == "4":
            return "jumbo" if wake in "HJ" else "regional"  # 4-jet medium: BAe 146 / Avro RJ
        if has(name, WIDE_TWIN_OR_TRI) or (wake == "H" and engines in "23"):
            return "widebody"
        if wake == "L":
            return "bizjet"
        if wake == "M" and name.split()[0] in ("AIRBUS", "BOEING", "EMBRAER", "BOMBARDIER", "MCDONNELL",
                                                "DOUGLAS", "TUPOLEV", "YAKOVLEV", "COMAC", "IRKUT", "FOKKER",
                                                "BAC", "SUD", "CANADAIR", "DE HAVILLAND", "ANTONOV"):
            return "narrowbody"
        return None
    if power in "TP":
        if engines == "1":
            return "single"
        if wake == "H" or has(name, AIRLIFTER):
            return "airlifter"
        if power == "P":
            return "twin" if engines == "2" else "turboprop"
        return "turboprop"
    # Gliders, balloons, gyrocopters, electric and the rest: a light single is the closest outline.
    return "single"


def base37(code):
    v = 0
    for ch in code.ljust(4, "\0")[:4]:
        v = v * 37 + (0 if ch == "\0" else ALPHABET.index(ch) + 1)
    return v


def load_types(path):
    raw = open(path, "rb").read()
    if raw[:2] == b"\x1f\x8b":
        raw = gzip.decompress(raw)
    return json.loads(raw)


def load_overrides(path):
    out = {}
    with open(path, newline="") as f:
        for row in csv.reader(line for line in f if not line.startswith("#")):
            if not row or row[0] == "type":
                continue
            code, fam = row[0].strip().upper(), row[1].strip()
            if fam not in FAMILIES:
                sys.exit(f"{path}: unknown family {fam!r} for {code}")
            out[code] = fam
    return out


def table(types, overrides):
    out, unclassified = {}, []
    for code, (name, desc, wake) in sorted(types.items()):
        code = code.upper()
        if not all(c in ALPHABET for c in code) or not 2 <= len(code) <= 4:
            continue
        fam = overrides.get(code) or classify(code, name.upper(), desc, wake)
        if fam is None:
            unclassified.append(f"{code},{name},{desc},{wake}")
            continue
        out[code] = fam
    for code, fam in overrides.items():  # overrides may name types the list lacks
        out[code] = fam
    return out, unclassified


def half_units(v):
    h = round(v * 2)
    assert 0 <= h <= 255 and abs(h - v * 2) < 1e-6, v
    return h


def emit_family(f):
    def flat(rows, n):
        assert all(len(r) == n for r in rows)
        return [half_units(x) for r in rows for x in r]

    t, te, tl = f["t"], f.get("te", []), f.get("tl", [])
    s, se, sl = f["s"], f.get("se", []), f.get("sl", [])
    assert t[0][0] == 0 and t[-1][0] == 0, f["key"] + ": the half outline must start and end on the centreline"
    data = flat(t, 2) + flat(te, 4) + flat(tl, 4) + flat(s, 2) + flat(se, 4) + flat(sl, 4)
    counts = [len(t), len(te), len(tl), len(s), len(se), len(sl)]
    return data, counts


def write(out_path, fams, tab):
    lines = ["// Generated by tools/gen_shapes.py from tools/shapes_outlines.json, tools/shapes_overrides.csv",
             "// and tar1090-db's ICAO Doc 8643 type list. Do not edit.",
             '#include "Shapes.h"', "", "namespace data {", "", "// clang-format off"]
    for f in fams:
        data, _ = emit_family(f)
        rows = [", ".join(str(x) for x in data[i:i + 24]) for i in range(0, len(data), 24)]
        lines.append(f"static const uint8_t k_{f['key']}[] = {{")
        lines += [f"    {r}," for r in rows]
        lines.append("};")
    lines.append("const ShapeDef kShapes[kFamilyCount] = {")
    wake_px = {"L": 13, "M": 16, "H": 20, "J": 22}
    for f in fams:
        _, c = emit_family(f)
        lines.append(f"    {{k_{f['key']}, {c[0]}, {c[1]}, {c[2]}, {c[3]}, {c[4]}, {c[5]}, "
                     f"{'true' if f.get('rotor') else 'false'}, {wake_px[f['wake']]}}},")
    lines.append("};")
    packed = sorted(base37(code) << 4 | (FAMILIES.index(fam) + 1) for code, fam in tab.items())
    lines.append(f"const uint32_t kTypeFamilies[] = {{")
    for i in range(0, len(packed), 8):
        lines.append("    " + ", ".join(f"0x{v:07X}u" for v in packed[i:i + 8]) + ",")
    lines += ["};", "const int kTypeFamilyCount = sizeof(kTypeFamilies) / sizeof(kTypeFamilies[0]);",
              "// clang-format on", "", "}  // namespace data", ""]
    with open(out_path, "w") as f:
        f.write("\n".join(lines))
    return len(packed)


def selftest():
    assert base37("") == 0 and base37("A") == 11 * 37 ** 3 and base37("ZZZZ") < 1 << 21
    assert classify("X", "BOEING 787-9", "L2J", "H") == "widebody"
```

```cpp
#pragma once
// Aircraft shape families (5a spec §5): 12 outlines, each a top view (nose up, 100-unit box) and a side
// view (nose right, 120 x 40 box), and the ICAO type -> family table. Outlines and table are generated
// by tools/gen_shapes.py into ShapeData.cpp.
#include <cstdint>

#include "gfx/Canvas.h"

namespace data {

enum class Family : uint8_t {
    None = 0,  // unknown: the screens draw gfx::planeGlyph
    Narrowbody, Widebody, Jumbo, Superjumbo, Regional, Bizjet, Turboprop, Single, Twin, Helicopter, FastJet,
    Airlifter,
};
constexpr int kFamilyCount = 12;

// One family's outlines, as uint8 half-units, in this order: top half outline (x, y) * topN, top engines
// (dx, y, rx, ry) * topEngN (mirrored), top lines (x0, y0, x1, y1) * topLineN (mirrored), side outline
// (x, y) * sideN, side engines (cx, cy, rx, ry) * sideEngN, side lines * sideLineN.
struct ShapeDef {
    const uint8_t* data;
    uint8_t topN, topEngN, topLineN, sideN, sideEngN, sideLineN;
    bool rotor;    // a rotor disc over the top view
    uint8_t iconPx;  // Radar and Map icon size, from the family's typical wake class
};
extern const ShapeDef kShapes[kFamilyCount];
// Sorted: the type code in base 37 (21 bits) << 4 | family.
extern const uint32_t kTypeFamilies[];
extern const int kTypeFamilyCount;

// The family for an ICAO type designator ("B789"), or None when the code is unknown or empty.
Family familyForType(const char* icaoType);
// The family for an ADS-B emitter category (0xA1 .. 0xA7), or None.
Family familyForCategory(uint8_t category);
// The type, else the category.
Family familyFor(const char* icaoType, uint8_t category);

// Radar and Map icon size in pixels (planeGlyph's 12 px for None).
int iconPx(Family f);

// The top view centred on (cx, cy), `px` pixels across the box, nose along headingDeg. Engines in the
// body colour; prop and rotor lines at `lineAlpha` of `a`. Family::None draws gfx::planeGlyph at px.
void drawTop(gfx::Canvas& c, Family f, float cx, float cy, float px, float headingDeg, gfx::Rgb col, uint8_t a = 255);
// The side view with its box's top-left at (x, y), `w` pixels wide (height w / 3), nose right; engines in
// `engine`. Nothing for Family::None.
void drawSide(gfx::Canvas& c, Family f, float x, float y, float w, gfx::Rgb body, gfx::Rgb engine, uint8_t a = 255);

}  // namespace data
```

```cpp
#include "Shapes.h"

#include <cmath>
#include <initializer_list>

#include "gfx/Math.h"
#include "gfx/Raster.h"

namespace data {
using namespace gfx;

namespace {
constexpr int kEllipseN = 14;  // points on an engine ellipse: round at 22 px, cheap at 13
constexpr uint8_t kLineAlpha = 140;

int digit37(char ch) {
    if (ch >= '0' && ch <= '9') return ch - '0' + 1;
    if (ch >= 'A' && ch <= 'Z') return ch - 'A' + 11;
    if (ch >= 'a' && ch <= 'z') return ch - 'a' + 11;
    return -1;
}

// An ellipse centred on (ex, ey) in box units, mapped through `map`.
template <class Map>
void ellipse(Canvas& c, float ex, float ey, float rx, float ry, const Map& map, Rgb col, uint8_t a) {
    Vec2 pts[kEllipseN];
    for (int i = 0; i < kEllipseN; ++i) {
        float t = i * (2 * 3.14159265f / kEllipseN);
        pts[i] = map(ex + rx * std::cos(t), ey + ry * std::sin(t));
    }
    aaPolygon(c, pts, kEllipseN, col, a);
}
}  // namespace

Family familyForType(const char* t) {
    if (!t || !t[0]) return Family::None;
    uint32_t v = 0;
    int n = 0;
    for (; t[n]; ++n) {
        int d = digit37(t[n]);
        if (n >= 4 || d < 0) return Family::None;
        v = v * 37 + uint32_t(d);
    }
    for (; n < 4; ++n) v *= 37;
    int lo = 0, hi = kTypeFamilyCount - 1;
    while (lo <= hi) {
        int mid = (lo + hi) / 2;
        uint32_t k = kTypeFamilies[mid] >> 4;
        if (k == v) return Family(kTypeFamilies[mid] & 0xF);
        if (k < v) lo = mid + 1;
        else hi = mid - 1;
    }
    return Family::None;
}

Family familyForCategory(uint8_t cat) {
    switch (cat) {
        case 0xA1: return Family::Single;
        case 0xA2: return Family::Bizjet;
        case 0xA3:
        case 0xA4: return Family::Narrowbody;
        case 0xA5: return Family::Widebody;
        case 0xA6: return Family::FastJet;
        case 0xA7: return Family::Helicopter;
        default: return Family::None;
    }
}

Family familyFor(const char* type, uint8_t cat) {
    Family f = familyForType(type);
    return f != Family::None ? f : familyForCategory(cat);
}

int iconPx(Family f) { return f == Family::None ? 12 : kShapes[int(f) - 1].iconPx; }

void drawTop(Canvas& c, Family f, float cx, float cy, float px, float headingDeg, Rgb col, uint8_t a) {
    if (f == Family::None) return planeGlyph(c, cx, cy, px, headingDeg, col, a);
    const ShapeDef& s = kShapes[int(f) - 1];
    const float k = px / 200.f;  // half-units to pixels
    const float sn = std::sin(headingDeg * kDeg), cs = std::cos(headingDeg * kDeg);
    // Box units (0..100, centre 50, 50) to screen, turned to the heading.
    auto map = [&](float x, float y) {
        float dx = (x - 50) * k * 2, dy = (y - 50) * k * 2;
        return Vec2{cx + dx * cs - dy * sn, cy + dx * sn + dy * cs};
    };
    const uint8_t* p = s.data;
    Vec2 pts[2 * 16];
    int n = 0;
    for (int i = 0; i < s.topN; ++i) pts[n++] = map(50 + p[2 * i] / 2.f, p[2 * i + 1] / 2.f);
    for (int i = s.topN - 1; i >= 0; --i)
        if (p[2 * i]) pts[n++] = map(50 - p[2 * i] / 2.f, p[2 * i + 1] / 2.f);
    aaPolygon(c, pts, n, col, a);
    p += s.topN * 2;
    for (int i = 0; i < s.topEngN; ++i, p += 4)
        for (int side : {1, -1}) ellipse(c, 50 + side * p[0] / 2.f, p[1] / 2.f, p[2] / 2.f, p[3] / 2.f, map, col, a);
    const uint8_t la = uint8_t((a * kLineAlpha + 127) / 255);
    const float lw = std::fmax(1.f, px / 60.f);
    for (int i = 0; i < s.topLineN; ++i, p += 4)
        for (int side : {1, -1}) {
            Vec2 a0 = map(50 + side * p[0] / 2.f, p[1] / 2.f), a1 = map(50 + side * p[2] / 2.f, p[3] / 2.f);
            aaLine(c, a0.x, a0.y, a1.x, a1.y, lw, col, la);
        }
    if (s.rotor) {
        Vec2 hub = map(50, 38);
        aaRing(c, hub.x, hub.y, 44 * k * 2, lw, col, la);
    }
}

void drawSide(Canvas& c, Family f, float x, float y, float w, Rgb body, Rgb engine, uint8_t a) {
    if (f == Family::None) return;
    const ShapeDef& s = kShapes[int(f) - 1];
    const float k = w / 240.f;  // half-units to pixels
    auto map = [&](float ux, float uy) { return Vec2{x + ux * 2 * k, y + uy * 2 * k}; };
    const uint8_t* p = s.data + s.topN * 2 + s.topEngN * 4 + s.topLineN * 4;
    Vec2 pts[16];
    for (int i = 0; i < s.sideN; ++i) pts[i] = map(p[2 * i] / 2.f, p[2 * i + 1] / 2.f);
    aaPolygon(c, pts, s.sideN, body, a);
    p += s.sideN * 2;
    for (int i = 0; i < s.sideEngN; ++i, p += 4) ellipse(c, p[0] / 2.f, p[1] / 2.f, p[2] / 2.f, p[3] / 2.f, map, engine, a);
    const float lw = std::fmax(1.f, w / 90.f);
    for (int i = 0; i < s.sideLineN; ++i, p += 4) {
        Vec2 a0 = map(p[0] / 2.f, p[1] / 2.f), a1 = map(p[2] / 2.f, p[3] / 2.f);
        aaLine(c, a0.x, a0.y, a1.x, a1.y, lw, body, a);
    }
}

}  // namespace data
```

```cpp
#include "Badge.h"

#include "Hot.h"

namespace gfx {

GFX_HOT void drawBadge(Canvas& c, const Badge& b, int x, int y, uint8_t a) {
    if (b.empty() || a == 0) return;
    const Rect area = Rect{x, y, b.w, b.h}.intersect(c.clip());
    if (area.empty()) return;
    const int rowBytes = (b.w * b.bpp + 7) / 8;
    for (int py = area.y; py < area.bottom(); ++py) {
        const uint8_t* row = b.px + (py - y) * rowBytes;
        for (int px = area.x; px < area.right(); ++px) {
            const int i = px - x;
            const uint8_t idx = b.bpp == 8 ? row[i] : uint8_t(i & 1 ? row[i >> 1] & 0x0F : row[i >> 1] >> 4);
            if (idx >= b.colours) continue;  // a corrupt index: leave the pixel
            uint32_t al = b.alpha[idx];
            if (a != 255) al = div255(al * a);
            if (!al) continue;
            uint16_t& d = c.at(px, py);
            d = al >= 255 ? b.pal[idx] : blend565(d, b.pal[idx], uint8_t(al));
        }
    }
}

}  // namespace gfx
```

```cpp
#include "TailFin.h"

#include <cmath>

#include "gfx/Raster.h"
#include "ui/Widgets.h"

namespace ui {
using namespace gfx;

namespace {
const Vec2 kFin[4] = {{10, 94}, {56, 8}, {84, 8}, {92, 94}};
const Vec2 kBand[4] = {{0, 74}, {100, 42}, {100, 60}, {0, 92}};
constexpr Rgb kCinematicTile{0x26, 0x30, 0x6A};
constexpr float kInset = 0.8f;  // the fin or shape fills 80 % of the tile

// Clip `in` (n points) to the convex, clockwise-on-screen polygon `clip`; returns the count in `out`.
int clipConvex(const Vec2* in, int n, const Vec2* clip, int m, Vec2* out) {
    Vec2 buf[16];
    Vec2* src = buf;
    for (int i = 0; i < n; ++i) src[i] = in[i];
    for (int e = 0; e < m && n; ++e) {
        const Vec2 a = clip[e], b = clip[(e + 1) % m];
        auto inside = [&](Vec2 p) { return (b.x - a.x) * (p.y - a.y) - (b.y - a.y) * (p.x - a.x) >= 0; };
        Vec2 next[16];
        int k = 0;
        for (int i = 0; i < n; ++i) {
            Vec2 p = src[i], q = src[(i + 1) % n];
            bool ip = inside(p), iq = inside(q);
            if (ip) next[k++] = p;
            if (ip != iq) {
                float d1 = (b.x - a.x) * (p.y - a.y) - (b.y - a.y) * (p.x - a.x);
                float d2 = (b.x - a.x) * (q.y - a.y) - (b.y - a.y) * (q.x - a.x);
                float t = d1 / (d1 - d2);
                next[k++] = {p.x + (q.x - p.x) * t, p.y + (q.y - p.y) * t};
            }
        }
        n = k;
        for (int i = 0; i < n; ++i) src[i] = next[i];
    }
    for (int i = 0; i < n; ++i) out[i] = src[i];
    return n;
}

float dist(Rgb a, Rgb b) {
    float dr = float(a.r) - b.r, dg = float(a.g) - b.g, db = float(a.b) - b.b;
    return std::sqrt(dr * dr + dg * dg + db * db);
}
}  // namespace

    if (dist(fill, color) >= 80) return color;
    const Rgb white{255, 255, 255}, ink{20, 20, 24};
    return contrastRatio(fill, white) >= contrastRatio(fill, ink) ? white : ink;
}

        const bool livery = al->fill.r || al->fill.g || al->fill.b;

        stripe = finStripe(fill, al->color);
    } else {
        fill = t.brandNeutral;
        stripe = lerp(fill, {255, 255, 255}, 0.45f);
    }
    const float k = side * kInset / 100.f, ox = x + side * (1 - kInset) / 2, oy = y + side * (1 - kInset) / 2;
    Vec2 fin[4], band[16];
    for (int i = 0; i < 4; ++i) fin[i] = {ox + kFin[i].x * k, oy + kFin[i].y * k};
```

```cpp
#pragma once
// Storage for tests: files held in memory, so a test can build, truncate or corrupt a pack.
#include <cstring>
#include <map>
#include <memory>
#include <string>
#include <vector>

#include "hal.h"

struct MemFile : hal::IFile {
    std::vector<uint8_t> bytes;
    bool fail = false;  // every read fails, as when the card is pulled
    int reads = 0;
    uint32_t size() const override { return uint32_t(bytes.size()); }
    bool readAt(uint32_t off, void* buf, uint32_t n) override {
        ++reads;
        if (fail || off > bytes.size() || bytes.size() - off < n) return false;
        std::memcpy(buf, bytes.data() + off, n);
        return true;
    }
};

struct MemStorage : hal::IStorage {
    bool isMounted = true;
    std::map<std::string, std::unique_ptr<MemFile>> files;
    MemFile& add(const std::string& path, const std::string& data) {
        auto& f = files[path];
        f = std::make_unique<MemFile>();
        f->bytes.assign(data.begin(), data.end());
        return *f;
    }
    bool mounted() const override { return isMounted; }
    hal::IFile* open(const char* path) override {
        if (!isMounted) return nullptr;
        auto it = files.find(path);
        return it == files.end() ? nullptr : it->second.get();
    }
};
```

### Task 8: The pack format — `build_pack.py` and `assets::Pack`

**Files:**
- Create: `tools/build_pack.py`, `firmware/lib/core/assets/Pack.h`, `firmware/lib/core/assets/Pack.cpp`, `firmware/test/test_pack/test_main.cpp`

The format (spec §2, with per-size CRCs, see "Decisions"), little-endian:

```
Header, 32 bytes: "CPAK", u16 version (1), u16 kind (1 = logos), u32 count, u32 indexOffset (32),
                  u32 dataOffset, u32 builtUnix, 8 bytes zero.
Index, count x 12 bytes, sorted by key: char key[4] (NUL-padded), u32 offset (from file start), u32 size.
Logo item:  u8 sizeCount, then per size 8 bytes: u8 w, u8 h, u8 bpp, u8 colours, u32 offset (within the item).
            Each size block: colours x (u16 RGB565, u8 alpha), then the pixels (rows padded to a byte at
            4 bpp, high nibble first), then u16 CRC-16/CCITT-FALSE of the block's bytes before it.
```

- [ ] **Step 1: Write `tools/build_pack.py`.** It has the pack writer (used for the real pack and the test fixture) and the logo encoder.

```python
#!/usr/bin/env python3
"""Build logos.pak (5a spec §2-3) from a folder of airline logos named <ICAO>.png.

Each logo is scaled to 40, 30 and 25 px (Lanczos), given rounded corners as alpha, and quantised: 40 and 30
px to <= 128 colours at 8 bpp, 25 px to 16 colours at 4 bpp. The pack layout is documented in
firmware/lib/core/assets/Pack.h. Needs Pillow (tools/.venv).

  tools/.venv/bin/python -I tools/build_pack.py --logos assets/logos --out logos.pak [--only UAL,DAL]
  tools/.venv/bin/python -I tools/build_pack.py --selftest

Copy logos.pak to /contrail/ on a FAT32 card. Exit codes: 0 written, 2 no logos found.
"""
import argparse
import os
import struct
import sys
import time

from PIL import Image, ImageDraw

MAGIC, VERSION, KIND_LOGOS = b"CPAK", 1, 1
SIZES = [(40, 8, 128), (30, 8, 128), (25, 4, 16)]  # side, bpp, colours


def crc16(data, crc=0xFFFF):
    """CRC-16/CCITT-FALSE, as assets::crc16."""
    for b in data:
        crc ^= b << 8
        for _ in range(8):
            crc = ((crc << 1) ^ 0x1021) if crc & 0x8000 else crc << 1
            crc &= 0xFFFF
    return crc


def rgb565(r, g, b):
    return ((r & 0xF8) << 8) | ((g & 0xFC) << 3) | (b >> 3)


def write_pack(path, kind, items, built=None):
    """items: {key: bytes}. Keys are 1-4 ASCII characters."""
    keys = sorted(items)
    count = len(keys)
    index_off = 32
    data_off = index_off + 12 * count
    index, blob, off = b"", b"", data_off
    for k in keys:
        kb = k.encode("ascii")
        assert 1 <= len(kb) <= 4, k
        index += kb.ljust(4, b"\0") + struct.pack("<II", off, len(items[k]))
        blob += items[k]
        off += len(items[k])
    header = MAGIC + struct.pack("<HHIIII", VERSION, kind, count, index_off, data_off,
                                 int(time.time()) if built is None else built) + b"\0" * 8
    assert len(header) == 32
    with open(path, "wb") as f:
        f.write(header + index + blob)


def rounded(img, side):
    """img (RGBA, side x side) with corners of radius side/8 made transparent, anti-aliased by 4x supersampling."""
    r = side / 8
    big = Image.new("L", (side * 4, side * 4), 0)
    ImageDraw.Draw(big).rounded_rectangle([0, 0, side * 4 - 1, side * 4 - 1], radius=r * 4, fill=255)
    mask = big.resize((side, side), Image.Resampling.LANCZOS)
    out = img.copy()
    a = out.getchannel("A")
    out.putalpha(Image.composite(a, Image.new("L", a.size, 0), mask))
    return out


def encode_size(src, side, bpp, colours):
    im = src.convert("RGBA").resize((side, side), Image.Resampling.LANCZOS)
    im = rounded(im, side)
    q = im.quantize(colors=colours, method=Image.Quantize.FASTOCTREE, dither=Image.Dither.NONE)
    pal = q.getpalette("RGBA")
    used = max(q.getdata()) + 1 if side else 0
    block = b""
    for i in range(used):
        r, g, b, a = pal[4 * i:4 * i + 4]
        block += struct.pack("<HB", rgb565(r, g, b), a)
    px = list(q.getdata())
    if bpp == 8:
        block += bytes(px)
    else:
        for y in range(side):
            row = px[y * side:(y + 1) * side] + [0]
            block += bytes((row[x] << 4) | row[x + 1] for x in range(0, side, 2))
    block += struct.pack("<H", crc16(block))
    return used, block


def encode_logo(path):
    src = Image.open(path)
    head = struct.pack("<B", len(SIZES))
    blocks, off = b"", 1 + 8 * len(SIZES)
    for side, bpp, colours in SIZES:
        used, block = encode_size(src, side, bpp, colours)
        head += struct.pack("<BBBBI", side, side, bpp, used, off)
        blocks += block
        off += len(block)
    return head + blocks


def selftest():
    assert crc16(b"123456789") == 0x29B1  # the CRC-16/CCITT-FALSE check value
    assert rgb565(255, 255, 255) == 0xFFFF
    print("selftest ok")


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--logos")
    ap.add_argument("--out")
    ap.add_argument("--only", help="comma-separated ICAO codes (test fixtures)")
    ap.add_argument("--built", type=int, help="fixed build time, for reproducible fixtures")
    ap.add_argument("--selftest", action="store_true")
    a = ap.parse_args()
    if a.selftest:
        return selftest()
    only = set(a.only.split(",")) if a.only else None
    items = {}
    for name in sorted(os.listdir(a.logos)):
        code, ext = os.path.splitext(name)
        if ext.lower() != ".png" or not 3 <= len(code) <= 4 or (only and code not in only):
            continue
        items[code.upper()] = encode_logo(os.path.join(a.logos, name))
    if not items:
        print("no logos found")
        return 2
    write_pack(a.out, KIND_LOGOS, items, a.built)
    size = os.path.getsize(a.out)
    print(f"wrote {a.out}: {len(items)} logos, {size / 1e6:.1f} MB")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```cpp
#include "Pack.h"

#include <cstring>

namespace assets {

namespace {
uint16_t le16(const uint8_t* p) { return uint16_t(p[0] | p[1] << 8); }
uint32_t le32(const uint8_t* p) { return uint32_t(p[0]) | uint32_t(p[1]) << 8 | uint32_t(p[2]) << 16 | uint32_t(p[3]) << 24; }
constexpr uint32_t kHeader = 32, kEntry = 12;
}  // namespace

uint16_t crc16(const uint8_t* p, size_t n, uint16_t crc) {
    for (size_t i = 0; i < n; ++i) {
        crc ^= uint16_t(p[i]) << 8;
        for (int b = 0; b < 8; ++b) crc = crc & 0x8000 ? uint16_t((crc << 1) ^ 0x1021) : uint16_t(crc << 1);
    }
    return crc;
}

bool Pack::open(hal::IFile* f, uint16_t kind) {
    f_ = nullptr, count_ = 0, version_ = 0;
    if (!f) return error_ = PackError::NotOpen, false;
    uint8_t h[kHeader];
    if (f->size() < kHeader || !f->readAt(0, h, kHeader)) return error_ = PackError::Truncated, false;
    if (std::memcmp(h, "CPAK", 4)) return error_ = PackError::BadMagic, false;
    version_ = le16(h + 4);
    if (version_ != kVersion) return error_ = PackError::BadVersion, false;
    if (le16(h + 6) != kind) return error_ = PackError::BadKind, false;
    const uint32_t count = le32(h + 8), index = le32(h + 12);
    if (index < kHeader || index > f->size() || (f->size() - index) / kEntry < count)
        return error_ = PackError::Truncated, false;
    f_ = f, count_ = count, indexOffset_ = index, error_ = PackError::None;
    return true;
}

bool Pack::find(const char* key, uint32_t& offset, uint32_t& size) {
    if (!f_ || !key || !key[0]) return false;
    char want[4] = {};
    for (int i = 0; i < 4 && key[i]; ++i) want[i] = key[i];
    if (std::strlen(key) > 4) return false;
    int lo = 0, hi = int(count_) - 1;
    while (lo <= hi) {
        const int mid = (lo + hi) / 2;
        uint8_t e[kEntry];
        if (!f_->readAt(indexOffset_ + uint32_t(mid) * kEntry, e, kEntry)) return false;
        const int cmp = std::memcmp(e, want, 4);
        if (cmp == 0) {
            offset = le32(e + 4), size = le32(e + 8);
            return offset <= f_->size() && f_->size() - offset >= size;
        }
        if (cmp < 0) lo = mid + 1;
        else hi = mid - 1;
    }
    return false;
}

bool Pack::read(uint32_t offset, void* buf, uint32_t n) { return f_ && f_->readAt(offset, buf, n); }

}  // namespace assets
```

Keys compare as unsigned bytes with `memcmp`, which matches Python's `sorted()` on ASCII strings padded with NUL (shorter keys sort first, as `"AAL\0" < "AALA"`). Python sorts the *unpadded* strings; for keys of 3–4 uppercase letters and digits the two orders agree.

```python
import argparse
import json
import os
import sys
import urllib.request

REPO, COMMIT = "Jxck-S/airline-logos", "e0b218991caef4832e0db911136173e8eead942a"
SETS = ["flightaware_logos", "radarbox_logos"]  # first wins


def tree():
    url = f"https://api.github.com/repos/{REPO}/git/trees/{COMMIT}?recursive=1"
    with urllib.request.urlopen(url, timeout=60) as r:
        return [e["path"] for e in json.load(r)["tree"] if e["type"] == "blob"]

    ap.add_argument("--out", required=True)
    a = ap.parse_args()
    os.makedirs(a.out, exist_ok=True)
    chosen = {}
    paths = tree()
    for s in reversed(SETS):  # later sets first, so the first set overwrites them
        for p in paths:
            folder, _, name = p.partition("/")
            code, ext = os.path.splitext(name)
            if folder == s and ext.lower() == ".png" and 3 <= len(code) <= 4 and code.isalnum():
                chosen[code.upper()] = p
    failed = 0
    for code, p in sorted(chosen.items()):
        dest = os.path.join(a.out, code + ".png")
        if os.path.exists(dest):
            continue
        url = f"https://raw.githubusercontent.com/{REPO}/{COMMIT}/{p}"
        try:
            with urllib.request.urlopen(url, timeout=60) as r, open(dest, "wb") as f:
                f.write(r.read())
        except OSError as e:
            print(f"{code}: {e}")
            failed += 1
    print(f"{len(chosen)} logos, {failed} failed")
    return 1 if failed else 0


if __name__ == "__main__":
    sys.exit(main())
```

```cpp
#include <cstring>

#include "services/Log.h"

uint32_t le32(const uint8_t* p) { return uint32_t(p[0]) | uint32_t(p[1]) << 8 | uint32_t(p[2]) << 16 | uint32_t(p[3]) << 24; }
constexpr int kMaxSizes = 4;
}  // namespace

void LogoStore::begin(hal::IStorage* storage) {
    mounted_ = storage && storage->mounted();
    error_[0] = 0;
    if (!mounted_) return;
    hal::IFile* f = storage->open(kPath);
    if (!f) return (void)std::snprintf(error_, sizeof error_, "no logos.pak");
    if (pack_.open(f, Pack::kKindLogos)) {
        svc::logf("[sd] logos.pak: %u logos", unsigned(pack_.count()));
        return;
    }
    switch (pack_.error()) {
        case PackError::BadVersion:
            std::snprintf(error_, sizeof error_, "logos.pak is version %u; this firmware reads %u",
                          unsigned(pack_.version()), unsigned(Pack::kVersion));
            break;
        case PackError::BadMagic: std::snprintf(error_, sizeof error_, "logos.pak is not a Contrail pack"); break;
        case PackError::BadKind: std::snprintf(error_, sizeof error_, "logos.pak is not a logo pack"); break;
        default: std::snprintf(error_, sizeof error_, "logos.pak is truncated"); break;
    }
    svc::logf("[sd] %s", error_);
}

void LogoStore::readFailed() {
    if (failed_.exchange(true)) return;
    std::snprintf(error_, sizeof error_, "SD card read failed");
    svc::logf("[sd] read failed: logos off until restart");
}

bool LogoStore::loadSize(const char* icao, int side, int bpp, int maxColours, uint16_t* pal, uint8_t* alpha,
                         uint8_t* px, size_t pxBytes, gfx::Badge& badge) {
    if (failed_ || !pack_.isOpen() || !icao || !icao[0]) return false;
    uint32_t off, size;
    if (!pack_.find(icao, off, size)) return false;
    uint8_t head[1 + 8 * kMaxSizes];
    if (size < 1 || !pack_.read(off, head, 1)) return readFailed(), false;
    const int n = head[0];
    if (n < 1 || n > kMaxSizes || size < uint32_t(1 + 8 * n)) return false;
    if (!pack_.read(off + 1, head + 1, uint32_t(8 * n))) return readFailed(), false;
    for (int i = 0; i < n; ++i) {
        const uint8_t* d = head + 1 + 8 * i;
        if (d[0] != side || d[1] != side || d[2] != bpp) continue;
        const int colours = d[3];
        const uint32_t at = le32(d + 4);
        const uint32_t pixels = uint32_t((side * bpp + 7) / 8) * uint32_t(side);
        const uint32_t block = uint32_t(colours) * 3 + pixels;
        if (colours < 1 || colours > maxColours || pixels > pxBytes || at > size || size - at < block + 2) return false;
        // The palette (3 bytes an entry) and the CRC through a small buffer; the pixels straight into place.
        uint16_t crc = 0xFFFF;
        uint8_t entry[3 * 16];
        for (int c = 0; c < colours; c += 16) {
            const int k = colours - c < 16 ? colours - c : 16;
            if (!pack_.read(off + at + uint32_t(3 * c), entry, uint32_t(3 * k))) return readFailed(), false;
            crc = crc16(entry, size_t(3 * k), crc);
            for (int j = 0; j < k; ++j) pal[c + j] = uint16_t(entry[3 * j] | entry[3 * j + 1] << 8), alpha[c + j] = entry[3 * j + 2];
        }
        uint8_t tail[2];
        if (!pack_.read(off + at + uint32_t(3 * colours), px, pixels) || !pack_.read(off + at + block, tail, 2))
            return readFailed(), false;
        crc = crc16(px, pixels, crc);
        if (crc != uint16_t(tail[0] | tail[1] << 8)) {
            svc::logf("[sd] %s: %dpx logo failed its CRC", icao, side);
            return false;
        }
        badge = gfx::Badge{uint8_t(side), uint8_t(side), uint8_t(bpp), uint8_t(colours), pal, alpha, px};
        return true;
    }
    return false;
}

}  // namespace assets
```
