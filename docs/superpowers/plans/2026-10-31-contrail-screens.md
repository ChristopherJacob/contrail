# Contrail Screens (Sub-project 2, pass 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the core demo screen with four real screens (Closest Flight, Radar, Departure Board, Look-Up Sky View), a screen host with fade transitions, touch gestures, and a smart director.

**Architecture:** A `ScreenApp` in `lib/core/screens/` owns a `Scene` (a value snapshot of flights, routes, sun and moon, rebuilt by `CoreApp` at 5 Hz), four `Screen`s (each a stack of `gfx::Layer`s), a `ScreenHost` (one composite layer the `StripRenderer` draws; it runs the active screen and dips through a dark veil to switch), a `GestureDetector` and a `Director`. Screens draw only what changed, using the existing damage tracking. All colours come from a `Theme`.

**Tech Stack:** C++17, PlatformIO (`cyd2usb`, `sim`, `test` envs), Unity tests, golden PPM images, existing `gfx` strip renderer.

**Spec:** `docs/superpowers/specs/2026-10-31-contrail-screens-design.md`

---

## Decisions made while planning (deviations from the spec)

1. **Transitions dip through a dark veil, not "foreground over a live shared sky".** Only Closest Flight (top band) and the Departure Board (header) show the vertical sky; Sky View's dome is radial and Radar has its own background, so there is no single sky to share. Every transition is: 0.2 s fade to the theme's veil colour, swap, 0.2 s fade in. One code path, cheap, no double rendering. The `SkyLayer` is reused by Closest Flight and Board, each limited to its own area.
2. **Scene holds the nearest 32 aircraft** (radar draws those). Fps targets are still measured with 40+ in range.
3. **Data tables are smaller than the spec's estimates:** ~130 aircraft types and ~70 airlines, the common ones. Unknown codes fall back as the spec says.
4. **Heap target in "Done when" becomes ≥ 55 KB free** (was ≥ 65 KB): the scene, snapshot buffer and screen tables add ~12 KB of static memory. The largest-free-block target (≥ 16 KB, the one TLS needs) is unchanged. Update the spec in Task 18.
5. **Fonts:** the existing Inter fonts (`kFontSmall` 10 px … `kFontHero` 34 px) are used; the mockups' condensed face is not added in pass 1.
6. **Stale planes:** the spec's "fade out after 2 minutes" is covered by the existing `AircraftStore` (dead reckoning for 30 s, dropped after 60 s without data); screens add only the "offline" badge.
7. **Director bookkeeping:** the director holds the screen it last asked for (not the host's current one), so a switch is not undone while the host is still fading out of the old screen.

```cpp
// to redraw (hash what is drawn, not the raw values, which drift by unseen amounts).
#include <cstddef>
#include <cstdint>

namespace ui {

constexpr uint32_t kHashSeed = 2166136261u;
uint32_t hashBytes(const void* p, size_t n, uint32_t h = kHashSeed);
uint32_t hashStr(const char* s, uint32_t h = kHashSeed);

void formatThousands(char* out, size_t n, int32_t v);  // 34000 → "34,000"
void formatAltitude(char* out, size_t n, int32_t ft);  // "34,000 ft"
void formatHundreds(char* out, size_t n, int32_t ft);  // 34000 → "340" (radar/board tags)
void formatDistance(char* out, size_t n, float nm);    // "2.4 nm" under 10, else "15 nm"
void formatClock(char* out, size_t n, int64_t epoch);  // local "HH:MM"
void formatVrate(char* out, size_t n, int16_t fpm);    // "↑ 1,200 fpm", "↓ 600 fpm", "level"
```

`lib/core/ui/Format.cpp`:

```cpp
#include "Format.h"

#include <cmath>
#include <cstdio>
#include <cstdlib>
#include <ctime>

namespace ui {

uint32_t hashBytes(const void* p, size_t n, uint32_t h) {
    auto b = static_cast<const uint8_t*>(p);
    for (size_t i = 0; i < n; ++i) h = (h ^ b[i]) * 16777619u;
    return h;
}

uint32_t hashStr(const char* s, uint32_t h) {
    for (; *s; ++s) h = (h ^ uint8_t(*s)) * 16777619u;
    return (h ^ 0xFF) * 16777619u;  // terminator, so "ab"+"c" differs from "a"+"bc"
}

void formatThousands(char* out, size_t n, int32_t v) {
    int32_t a = std::abs(v);
    if (a >= 1000) std::snprintf(out, n, "%s%d,%03d", v < 0 ? "-" : "", int(a / 1000), int(a % 1000));
    else std::snprintf(out, n, "%d", int(v));
}

void formatAltitude(char* out, size_t n, int32_t ft) {
    char num[16];
    formatThousands(num, sizeof num, ft);
    std::snprintf(out, n, "%s ft", num);
}

void formatHundreds(char* out, size_t n, int32_t ft) {
    std::snprintf(out, n, "%03d", int(ft < 0 ? 0 : ft / 100));
}

void formatDistance(char* out, size_t n, float nm) {
    if (nm < 9.95f) std::snprintf(out, n, "%.1f nm", nm);
    else std::snprintf(out, n, "%d nm", int(nm + 0.5f));
}

void formatClock(char* out, size_t n, int64_t epoch) {
    std::time_t t = std::time_t(epoch);
    std::tm tm{};
    localtime_r(&t, &tm);
    std::snprintf(out, n, "%02d:%02d", tm.tm_hour, tm.tm_min);
}

void formatVrate(char* out, size_t n, int16_t fpm) {
    if (std::abs(fpm) < 300) {
        std::snprintf(out, n, "level");
        return;
    }
    char num[16];
    int rounded = (std::abs(fpm) + 50) / 100 * 100;
    formatThousands(num, sizeof num, rounded);
    std::snprintf(out, n, "%s %s fpm", fpm > 0 ? "↑" : "↓", num);
}

const char* compassPoint(float b) {
    static const char* const kPts[] = {"N", "NE", "E", "SE", "S", "SW", "W", "NW"};
    int i = int(std::floor((b + 22.5f) / 45.f)) % 8;
    return kPts[i < 0 ? i + 8 : i];
}

const char* trendArrow(int16_t fpm) { return fpm >= 300 ? "↑" : fpm <= -300 ? "↓" : ""; }

}  // namespace ui
```

```cpp
#include "Astro.h"

#include <cmath>

namespace svc {
namespace {

constexpr double kDeg = M_PI / 180.0;

double rev(double x) { return x - 360.0 * std::floor(x / 360.0); }
double sind(double x) { return std::sin(x * kDeg); }
double cosd(double x) { return std::cos(x * kDeg); }

double julianDay(int64_t epoch) { return epoch / 86400.0 + 2440587.5; }

// Local sidereal time in degrees.
double localSidereal(int64_t epoch, double lon) {
    double jd = julianDay(epoch);
    return rev(280.46061837 + 360.98564736629 * (jd - 2451545.0) + lon);
}

HorizPos fromHourAngle(double haDeg, double decDeg, double lat) {
    double sinAlt = sind(lat) * sind(decDeg) + cosd(lat) * cosd(decDeg) * cosd(haDeg);
    double alt = std::asin(sinAlt) / kDeg;
    double az = std::atan2(-sind(haDeg) * cosd(decDeg), cosd(lat) * sind(decDeg) - sind(lat) * cosd(decDeg) * cosd(haDeg));
    return {alt, rev(az / kDeg)};
}

}  // namespace

HorizPos equatorialToHorizontal(double ra, double dec, int64_t epoch, double lat, double lon) {
    return fromHourAngle(localSidereal(epoch, lon) - ra, dec, lat);
}

MoonState moonState(int64_t epoch, double lat, double lon) {
    // Days since 2000 Jan 0.0 UT, the epoch of Schlyter's elements.
    double d = julianDay(epoch) - 2451543.5;
    double N = rev(125.1228 - 0.0529538083 * d), i = 5.1454, w = rev(318.0634 + 0.1643573223 * d);
    double a = 60.2666, e = 0.054900, M = rev(115.3654 + 13.0649929509 * d);
    double ws = rev(282.9404 + 4.70935e-5 * d), Ms = rev(356.0470 + 0.9856002585 * d);

    double E = M + (180 / M_PI) * e * sind(M) * (1 + e * cosd(M));
    for (int k = 0; k < 5; ++k) E = E - (E - (180 / M_PI) * e * sind(E) - M) / (1 - e * cosd(E));
    double xv = a * (cosd(E) - e), yv = a * std::sqrt(1 - e * e) * sind(E);
    double v = std::atan2(yv, xv) / kDeg, r = std::sqrt(xv * xv + yv * yv);
    double xh = r * (cosd(N) * cosd(v + w) - sind(N) * sind(v + w) * cosd(i));
    double yh = r * (sind(N) * cosd(v + w) + cosd(N) * sind(v + w) * cosd(i));
    double zh = r * sind(v + w) * sind(i);
    double lonEcl = rev(std::atan2(yh, xh) / kDeg);
    double latEcl = std::atan2(zh, std::sqrt(xh * xh + yh * yh)) / kDeg;

    // The largest perturbations (evection, variation, yearly equation, …).
    double Ls = rev(Ms + ws), Lm = rev(M + w + N), D = rev(Lm - Ls), F = rev(Lm - N);
    lonEcl += -1.274 * sind(M - 2 * D) + 0.658 * sind(2 * D) - 0.186 * sind(Ms) - 0.059 * sind(2 * M - 2 * D) -
              0.057 * sind(M - 2 * D + Ms) + 0.053 * sind(M + 2 * D) + 0.046 * sind(2 * D - Ms) +
              0.041 * sind(M - Ms) - 0.035 * sind(D) - 0.031 * sind(M + Ms) - 0.015 * sind(2 * F - 2 * D) +
              0.011 * sind(M - 4 * D);
    latEcl += -0.173 * sind(F - 2 * D) - 0.055 * sind(M - F - 2 * D) - 0.046 * sind(M + F - 2 * D) +
              0.033 * sind(F + 2 * D) + 0.017 * sind(2 * M + F);
    r += -0.58 * cosd(M - 2 * D) - 0.46 * cosd(2 * D);

    double ecl = 23.4393 - 3.563e-7 * d;
    double xe = cosd(lonEcl) * cosd(latEcl);
    double ye = sind(lonEcl) * cosd(latEcl) * cosd(ecl) - sind(latEcl) * sind(ecl);
    double ze = sind(lonEcl) * cosd(latEcl) * sind(ecl) + sind(latEcl) * cosd(ecl);
    double ra = rev(std::atan2(ye, xe) / kDeg), dec = std::atan2(ze, std::sqrt(xe * xe + ye * ye)) / kDeg;

    HorizPos h = equatorialToHorizontal(ra, dec, epoch, lat, lon);
    // Parallax: the moon is close enough that it sits ~1° lower than seen from Earth's centre.
    h.elevationDeg -= std::asin(1.0 / r) / kDeg * cosd(h.elevationDeg);

    // Phase from the moon's elongation from the sun.
    double sunLon = rev(Ms + ws + 1.915 * sind(Ms) + 0.020 * sind(2 * Ms));
    double cosElong = cosd(latEcl) * cosd(lonEcl - sunLon);
    MoonState m;
    m.elevationDeg = h.elevationDeg, m.azimuthDeg = h.azimuthDeg;
    m.illumination = (1 - cosElong) / 2;
    m.waxing = sind(lonEcl - sunLon) > 0;
    return m;
}

}  // namespace svc
```

```python
#!/usr/bin/env python3
"""Build firmware/lib/core/data/Stars.cpp from the Yale Bright Star Catalogue.

Downloads CDS catalogue V/50 (BSC5, fixed-width text), keeps stars brighter than
MAG_LIMIT and writes them as a constexpr table. The output is committed, so firmware
builds never need the network.

Usage: python3 tools/gen_stars.py
"""
import gzip
import urllib.request
from pathlib import Path

URL = "https://cdsarc.cds.unistra.fr/ftp/V/50/catalog.gz"
MAG_LIMIT = 3.5
OUT = Path(__file__).resolve().parent.parent / "firmware/lib/core/data/Stars.cpp"


def parse(line):
    """(ra, dec, mag) in degrees from one BSC5 record, or None (bytes per the V/50 ReadMe)."""
    if len(line) < 107 or not line[75:77].strip() or not line[102:107].strip():
        return None
    ra = (int(line[75:77]) + int(line[77:79]) / 60 + float(line[79:83]) / 3600) * 15
    dec = int(line[84:86]) + int(line[86:88]) / 60 + int(line[88:90]) / 3600
    if line[83] == "-":
        dec = -dec
    return ra, dec, float(line[102:107])


def main():
    raw = gzip.decompress(urllib.request.urlopen(URL, timeout=60).read()).decode("latin-1")
    stars = sorted(s for s in (parse(l) for l in raw.splitlines()) if s and s[2] <= MAG_LIMIT)
    sirius = [s for s in stars if s[2] < -1.3]
    assert sirius and abs(sirius[0][0] - 101.29) < 0.5, "catalogue layout changed: Sirius not found"
    lines = [
        "// Generated by tools/gen_stars.py from the Yale Bright Star Catalogue (CDS V/50). Do not edit.",
        '#include "Stars.h"',
        "",
        "namespace data {",
        "",
        "const Star kStars[] = {",
    ]
    lines += [f"    {{{ra:.3f}f, {dec:.3f}f, {mag:.2f}f}}," for ra, dec, mag in stars]
    lines += [
        "};",
        "const int kStarCount = sizeof(kStars) / sizeof(kStars[0]);",
        "",
        "}  // namespace data",
    ]
    OUT.write_text("\n".join(lines) + "\n")
    print(f"{len(stars)} stars -> {OUT}")


if __name__ == "__main__":
    main()
```

```cpp
void Canvas::radialGradient(const Rect& r, float cx, float cy, float rx, float ry, const Rgb* stops,
                            const float* pos, int n) {
    Rect a = r.intersect(clip_);
    if (a.empty()) return;
    // Indexed by the squared normalised radius so the inner loop needs no square root.
    constexpr int kSteps = 64;
    Rgb lut[kSteps];
    for (int i = 0; i < kSteps; ++i) lut[i] = sampleStops(stops, pos, n, std::sqrt(float(i) / (kSteps - 1)));
    float irx2 = 1.f / (rx * rx), iry2 = 1.f / (ry * ry);
    for (int y = a.y; y < a.bottom(); ++y) {
        float dy = y + 0.5f - cy, qy = dy * dy * iry2;
        uint16_t* p = &at(a.x, y);
        for (int x = a.x; x < a.right(); ++x) {
            float dx = x + 0.5f - cx, q = dx * dx * irx2 + qy;
            int i = q >= 1.f ? kSteps - 1 : int(q * (kSteps - 1) + 0.5f);
            *p++ = dither565(lut[i], x, y);
        }
    }
}
```

```cpp
    Rect area = r.intersect(c.clip());
    if (area.empty() || a == 0) return;
    uint16_t solid = rgb565(col);
    for (int y = area.y; y < area.bottom(); ++y) {

        if (yc < r.y + radius) dy = r.y + radius - yc;
        else if (yc > r.bottom() - radius) dy = yc - (r.bottom() - radius);
        float inset = dy > 0 ? radius - std::sqrt(std::fmax(0.f, radius * radius - dy * dy)) : 0.f;
        float xl = r.x + inset, xr = r.right() - inset;
        int x0 = std::max(area.x, int(std::floor(xl))), x1 = std::min(area.right(), int(std::ceil(xr)));
        for (int x = x0; x < x1; ++x) {

            if (cov <= 0) continue;

            else c.at(x, y) = blend565(c.at(x, y), solid, pa);
```

```cpp
struct RouteInfo {

    char orig[4] = "", dest[4] = "";

    bool get(const char* callsign, RouteInfo& out) const;

   private:
    mutable svc::Mutex mu_;
```

```cpp
namespace {
void copyStr(char* dst, size_t cap, const char* src) {

    dst[cap - 1] = 0;
}
}  // namespace

RouteInfo toRouteInfo(const prov::Route& r) {
    RouteInfo o;
    copyStr(o.callsign, sizeof o.callsign, r.callsign);
    copyStr(o.orig, sizeof o.orig, r.origIata);
    copyStr(o.dest, sizeof o.dest, r.destIata);
    copyStr(o.origCity, sizeof o.origCity, r.origCity);
    copyStr(o.destCity, sizeof o.destCity, r.destCity);
    copyStr(o.airline, sizeof o.airline, r.airline);
    o.origLat = r.origLat, o.origLon = r.origLon, o.destLat = r.destLat, o.destLon = r.destLon;
    return o;
}

void RouteShelf::put(const RouteInfo& r) {
    svc::LockGuard g(mu_);
    for (auto& e : e_)
        if (!std::strcmp(e.callsign, r.callsign)) return void(e = r);
    e_[next_] = r;
    next_ = (next_ + 1) % kMax;
}

bool RouteShelf::get(const char* cs, RouteInfo& out) const {
    svc::LockGuard g(mu_);
    for (auto& e : e_)
        if (e.callsign[0] && !std::strcmp(e.callsign, cs)) return out = e, true;
    return false;
}

}  // namespace app
```

```cpp
#include <cmath>
#include <cstring>

#include "data/Airlines.h"
#include "model/Geo.h"

namespace app {
namespace {
void copyStr(char* dst, size_t cap, const char* src) {
    std::strncpy(dst, src ? src : "", cap - 1);
    dst[cap - 1] = 0;
}
bool hasCoords(const RouteInfo& r) {
    return !std::isnan(r.origLat) && !std::isnan(r.origLon) && !std::isnan(r.destLat) && !std::isnan(r.destLon);
}
}  // namespace

float routeProgress(const RouteInfo& r, double lat, double lon) {
    if (!hasCoords(r)) return -1;
    double flown = geo::distanceNm(r.origLat, r.origLon, lat, lon);
    double left = geo::distanceNm(lat, lon, r.destLat, r.destLon);
    if (flown + left < 1) return -1;
    return float(flown / (flown + left));
}

int64_t estimateArrival(const RouteInfo& r, double lat, double lon, float gsKt, int32_t altFt, int64_t now) {
    if (!hasCoords(r) || gsKt < 60 || altFt < 1000 || now <= 0) return 0;
    double left = geo::distanceNm(lat, lon, r.destLat, r.destLon);
    return now + int64_t(left / gsKt * 3600.0);
}

void fillFlight(scr::SceneFlight& f, const model::Aircraft& a, const RouteInfo* route, int64_t now) {
    f = scr::SceneFlight{};
    f.hex = a.hex;
    copyStr(f.callsign, sizeof f.callsign, a.callsign[0] ? a.callsign : a.reg);
    copyStr(f.reg, sizeof f.reg, a.reg);
    copyStr(f.type, sizeof f.type, a.type);
    if (data::airlineForCallsign(a.callsign)) copyStr(f.airline, 4, a.callsign);
    f.altFt = a.altFt, f.vrateFpm = a.vrateFpm, f.gsKt = a.gsKt, f.trackDeg = a.trackDeg;
    f.distNm = a.distNm, f.bearingDeg = a.bearingDeg, f.elevDeg = a.elevDeg;
    f.military = a.has(model::AC_MILITARY), f.emergency = a.has(model::AC_EMERGENCY);
    if (!route) return;
    f.hasRoute = true;
    copyStr(f.orig, sizeof f.orig, route->orig);
    copyStr(f.dest, sizeof f.dest, route->dest);
    f.progress = routeProgress(*route, a.lat, a.lon);
    f.etaEpoch = estimateArrival(*route, a.lat, a.lon, a.gsKt, a.altFt, now);
}

}  // namespace app
```

```cpp
#pragma once
// Turns raw touch samples into taps and horizontal swipes. Resistive panels jitter a few
// pixels, so a tap tolerates small movement; events fire on release.
#include <cstdint>

namespace scr {

enum class Gesture : uint8_t { None, Tap, SwipeLeft, SwipeRight };

struct GestureEvent {
    Gesture gesture = Gesture::None;
    int x = 0, y = 0;  // where the press started
};

class GestureDetector {
   public:
    static constexpr int kTapSlop = 14, kSwipeMin = 50;
    static constexpr uint32_t kTapMaxMs = 600, kSwipeMaxMs = 900;
    GestureEvent feed(bool pressed, int x, int y, uint32_t nowMs);

   private:
    bool down_ = false;
    int x0_ = 0, y0_ = 0, x_ = 0, y_ = 0, maxMove_ = 0;
    uint32_t t0_ = 0;
};

}  // namespace scr
```

```cpp
#include "Gesture.h"

#include <cstdlib>

namespace scr {

GestureEvent GestureDetector::feed(bool pressed, int x, int y, uint32_t now) {
    if (pressed) {
        if (!down_) down_ = true, x0_ = x_ = x, y0_ = y_ = y, maxMove_ = 0, t0_ = now;
        x_ = x, y_ = y;
        int m = std::abs(x - x0_) + std::abs(y - y0_);
        if (m > maxMove_) maxMove_ = m;
        return {};
    }
    if (!down_) return {};
    down_ = false;
    uint32_t dur = now - t0_;
    int dx = x_ - x0_, dy = y_ - y0_;
    GestureEvent ev;
    ev.x = x0_, ev.y = y0_;
    if (std::abs(dx) >= kSwipeMin && std::abs(dx) > 2 * std::abs(dy) && dur <= kSwipeMaxMs)
        ev.gesture = dx < 0 ? Gesture::SwipeLeft : Gesture::SwipeRight;
    else if (maxMove_ <= kTapSlop && dur <= kTapMaxMs)
        ev.gesture = Gesture::Tap;
    return ev;
}

}  // namespace scr
```

```cpp
#pragma once
// Runs the active screen as a single composite layer for the strip renderer, and
// switches screens by dipping through the theme's veil colour: fade out, swap, fade in.
// Only the active screen is updated and drawn, so a transition never renders twice.
#include "Screen.h"
#include "Theme.h"

namespace scr {

class ScreenHost : public gfx::Layer {
   public:
    static constexpr float kFadeS = 0.2f;  // each half of a transition
    ScreenHost(Screen* const* screens, int n, const Theme& theme);

    Screen* screen(ScreenId id) const;
    ScreenId current() const { return cur_->id(); }
    // Where the host is heading (the current screen when idle).
    ScreenId target() const { return next_ ? next_->id() : cur_->id(); }
    bool transitioning() const { return phase_ != Phase::Idle; }
    uint8_t veilAlpha() const;

    void showNow(ScreenId id);  // cut without a fade (boot)
    void show(ScreenId id);     // fade; ignored if already there or heading there
    void setScene(const Scene* scene);
    void sceneChanged();        // the scene was rebuilt in place
    void setSelection(uint32_t hex);
    uint32_t selection() const { return selected_; }
    NavRequest tap(int x, int y);  // ignored mid-transition
    void addOverlay(gfx::Layer* layer);

    void update(float dt, gfx::DamageList& damage) override;
    void draw(gfx::Canvas& c) override;

   private:
    enum class Phase { Idle, Out, In };
    void activate(Screen* s);

    Screen* const* screens_;
    int n_;
    const Theme& theme_;
    Screen* cur_;
    Screen* next_ = nullptr;
    const Scene* scene_ = nullptr;
    uint32_t selected_ = 0;
    Phase phase_ = Phase::Idle;
    float t_ = 0;
    bool full_ = true;
    static constexpr int kMaxOverlays = 2;
    gfx::Layer* overlays_[kMaxOverlays] = {};
    int nOverlays_ = 0;
};

}  // namespace scr
```

`lib/core/screens/ScreenHost.cpp`:

```cpp
#include "ScreenHost.h"

namespace scr {

ScreenHost::ScreenHost(Screen* const* screens, int n, const Theme& theme)
    : screens_(screens), n_(n), theme_(theme), cur_(screens[0]) {}

Screen* ScreenHost::screen(ScreenId id) const {
    for (int i = 0; i < n_; ++i)
        if (screens_[i]->id() == id) return screens_[i];
    return nullptr;
}

uint8_t ScreenHost::veilAlpha() const {
    float f = t_ / kFadeS;
    if (f > 1) f = 1;
    if (phase_ == Phase::Out) return uint8_t(255 * f);
    if (phase_ == Phase::In) return uint8_t(255 * (1 - f));
    return 0;
}

void ScreenHost::activate(Screen* s) {
    cur_ = s;
    cur_->setScene(scene_);
    cur_->setSelection(selected_);
    cur_->enter();
    full_ = true;
}

void ScreenHost::showNow(ScreenId id) {
    Screen* s = screen(id);
    if (!s) return;
    next_ = nullptr, phase_ = Phase::Idle, t_ = 0;
    activate(s);
}

void ScreenHost::show(ScreenId id) {
    Screen* s = screen(id);
    if (!s || s == next_ || (s == cur_ && phase_ != Phase::Out)) return;
    if (phase_ == Phase::In) t_ = kFadeS * (1 - t_ / kFadeS);  // reverse from the current veil level
    else if (phase_ == Phase::Idle) t_ = 0;
    next_ = s, phase_ = Phase::Out;
}

void ScreenHost::setScene(const Scene* scene) {
    scene_ = scene;
    cur_->setScene(scene);
}

void ScreenHost::sceneChanged() { cur_->setScene(scene_); }

void ScreenHost::setSelection(uint32_t hex) {
    selected_ = hex;
    cur_->setSelection(hex);
}

NavRequest ScreenHost::tap(int x, int y) {
    if (phase_ != Phase::Idle) return {};
    return cur_->onTap(x, y);
}

void ScreenHost::addOverlay(gfx::Layer* layer) {
    if (nOverlays_ < kMaxOverlays) overlays_[nOverlays_++] = layer;
}

void ScreenHost::update(float dt, gfx::DamageList& damage) {
    if (phase_ != Phase::Idle) {
        t_ += dt;
        if (phase_ == Phase::Out && t_ >= kFadeS) {
            activate(next_);
            next_ = nullptr, phase_ = Phase::In, t_ = 0;
        } else if (phase_ == Phase::In && t_ >= kFadeS) {
            phase_ = Phase::Idle, t_ = 0;
            full_ = true;  // one clean frame without the veil
        }
    }
    if (full_ || phase_ != Phase::Idle) damage.addAll();
    full_ = false;
    gfx::Layer* const* ls = cur_->layers();
    for (int i = 0; i < cur_->layerCount(); ++i) ls[i]->update(dt, damage);
    for (int i = 0; i < nOverlays_; ++i) overlays_[i]->update(dt, damage);
}

void ScreenHost::draw(gfx::Canvas& c) {
    gfx::Layer* const* ls = cur_->layers();
    for (int i = 0; i < cur_->layerCount(); ++i) ls[i]->draw(c);
    for (int i = 0; i < nOverlays_; ++i) overlays_[i]->draw(c);
    if (uint8_t a = veilAlpha()) c.fillBlend(c.clip(), theme_.veil, a);
}

}  // namespace scr
```

```cpp
void ellipsize(char* out, size_t n, const FontData& f, const char* s, int maxW) {
    std::strncpy(out, s, n - 1);
    out[n - 1] = 0;
    if (textWidth(f, out) <= maxW) return;
    static const char kDots[] = "…";  // 3 bytes in UTF-8
    size_t len = std::strlen(out);
    while (len > 0) {
        do --len;
        while (len > 0 && (uint8_t(out[len]) & 0xC0) == 0x80);  // back up one whole character
        if (len + sizeof kDots > n) continue;
        std::memcpy(out + len, kDots, sizeof kDots);
        if (textWidth(f, out) <= maxW) return;
    }
    out[0] = 0;
}
```

```cpp
#include <cmath>
#include <cstdio>

namespace {

constexpr float kDeg = 3.14159265f / 180.f;

float wrap360(float a) {
    while (a >= 360.f) a -= 360.f;
    while (a < 0.f) a += 360.f;
    return a;
}

Vec2 polar(float cx, float cy, float r, float deg) { return {cx + std::sin(deg * kDeg) * r, cy - std::cos(deg * kDeg) * r}; }

// Bounding box of the pie slice from a0 to a1 (degrees clockwise from up, a0 <= a1).
Rect sectorBox(float cx, float cy, float r, float a0, float a1) {
    float x0 = cx, x1 = cx, y0 = cy, y1 = cy;
    auto add = [&](float a) {
        Vec2 p = polar(cx, cy, r, a);
        x0 = std::fmin(x0, p.x), x1 = std::fmax(x1, p.x), y0 = std::fmin(y0, p.y), y1 = std::fmax(y1, p.y);
    };
    add(a0), add(a1);
    for (float a = std::ceil(a0 / 90.f) * 90.f; a < a1; a += 90.f) add(a);
    return {int(x0) - 2, int(y0) - 2, int(x1 - x0) + 5, int(y1 - y0) + 5};
}

}  // namespace

void RadarScope::layout(Blip& b) const {

    if (!b.label) return;
    bool right = b.x < 170;
    Align al = right ? Align::Left : Align::Right;

    b.box = b.box.unite(ui::textBox(kFontSmall, lx, int(b.y) + 1, b.line1, al));
    b.box = b.box.unite(ui::textBox(kFontSmall, lx, int(b.y) + 11, b.line2, al));

uint8_t RadarScope::levelFor(const Blip& b) const {
    // Brightest just after the sweep passes, fading linearly over one turn to a faint glow.
    float since = wrap360(sweep_ - b.angle) / 360.f;
    float lit = 1.f - since * 0.85f;
    return uint8_t(lit * 15.f + 0.5f);
}

void RadarScope::syncScene(DamageList& damage) {
    sceneDirty_ = false;
    int prevN = n_;
    std::memcpy(prev_, blips_, sizeof(Blip) * size_t(prevN));
    n_ = 0;
    range_ = scene_ ? scene_->radiusNm : 25;
    int labels = 0;
    for (int i = 0; scene_ && i < scene_->count; ++i) {
        const SceneFlight& f = scene_->flights[i];
        if (f.distNm > range_ * 1.02f) continue;
        Blip& b = blips_[n_++];
        b = Blip{};
        b.hex = f.hex;
        float d = std::fmin(f.distNm / range_, 1.f) * kR;
        Vec2 p = polar(kCx, kCy, d, f.bearingDeg);
        b.x = p.x, b.y = p.y, b.angle = f.bearingDeg;
        b.selected = f.hex == selected_;
        b.label = labels < kLabels || b.selected;
        if (labels < kLabels) ++labels;
        std::snprintf(b.line1, sizeof b.line1, "%s", f.callsign);
        char h[6];
        ui::formatHundreds(h, sizeof h, f.altFt);
        std::snprintf(b.line2, sizeof b.line2, "%s%s", h, ui::trendArrow(f.vrateFpm));
        layout(b);
        b.level = levelFor(b);
        // Damage only what moved or changed.
        bool same = false;
        for (int k = 0; k < prevN; ++k) {
            if (prev_[k].hex != b.hex) continue;
            same = std::fabs(prev_[k].x - b.x) < 0.3f && std::fabs(prev_[k].y - b.y) < 0.3f &&
                   prev_[k].label == b.label && prev_[k].selected == b.selected &&
                   !std::strcmp(prev_[k].line1, b.line1) && !std::strcmp(prev_[k].line2, b.line2);
            if (!same) damage.add(prev_[k].box);
            prev_[k].hex = 0;  // matched
            break;
        }
        if (!same) damage.add(b.box);
    }
    for (int k = 0; k < prevN; ++k)
        if (prev_[k].hex) damage.add(prev_[k].box);  // gone
    std::snprintf(header_, sizeof header_, "RADAR · %d NM", int(range_ + 0.5f));
    std::snprintf(count_, sizeof count_, "%d aircraft", n_);
}

uint32_t RadarScope::hitTest(int x, int y, int maxPx) const {
    uint32_t best = 0;
    float bestD = float(maxPx * maxPx);
    for (int i = 0; i < n_; ++i) {
        float dx = blips_[i].x - x, dy = blips_[i].y - y, d = dx * dx + dy * dy;
        if (d <= bestD) bestD = d, best = blips_[i].hex;
    }
    return best;
}

void RadarScope::update(float dt, DamageList& damage) {
    float prev = sweep_;
    float step = 360.f / kTurnS * dt;
    sweep_ = wrap360(sweep_ + step);
    if (full_) damage.add({0, 0, 240, kBottom});
    else damage.add(sectorBox(kCx, kCy, kR + 2, prev - kTrailDeg, prev + step));
    if (sceneDirty_) syncScene(damage);
    for (int i = 0; i < n_; ++i) {
        uint8_t l = levelFor(blips_[i]);
        if (l != blips_[i].level) blips_[i].level = l, damage.add(blips_[i].box);
    }
    uint32_t sig = ui::hashStr(header_, ui::hashStr(count_));
    if (sig != headerSig_) damage.add({0, 6, 240, 18});
    headerSig_ = sig;
    full_ = false;
}
```

```cpp
constexpr int kOrderN = sizeof(kOrder) / sizeof(kOrder[0]);
}  // namespace

    host_.setScene(&scene_);
}

void ScreenApp::tick(uint32_t) {
    if (!started_) host_.showNow(ScreenId::Radar), started_ = true;
}

void ScreenApp::touch(bool pressed, int x, int y, uint32_t now) {
    GestureEvent ev = gestures_.feed(pressed, x, y, now);
    if (ev.gesture == Gesture::Tap) handle(host_.tap(ev.x, ev.y));
    else if (ev.gesture == Gesture::SwipeLeft) step(+1);
    else if (ev.gesture == Gesture::SwipeRight) step(-1);
}

void ScreenApp::handle(const NavRequest& r) {
    if (r.selectHex) host_.setSelection(r.selectHex);
    if (r.open) host_.show(r.to);
}

void ScreenApp::step(int dir) {
    int at = 0;
    for (int i = 0; i < kOrderN; ++i)
        if (kOrder[i] == host_.target()) at = i;
    for (int k = 1; k < kOrderN; ++k) {
        ScreenId id = kOrder[(at + dir * k + kOrderN * k) % kOrderN];
        if (host_.screen(id)) return host_.show(id);
    }
}
```

```cpp
// ------------------------------------------------------------------ PlaneBand

void PlaneBand::setFlight(const SceneFlight* f) {
    if (!f) {
        if (has_) full_ = true;
        has_ = false, hex_ = 0;
        return;
    }
    if (!has_ || f->hex != hex_) trail_ = 0, full_ = true;  // a new flight: start a fresh contrail
    has_ = true, hex_ = f->hex, heading_ = f->trackDeg, bearing_ = f->bearingDeg;
}

Rect PlaneBand::box() const {
    float a = heading_ * kDeg, tx = x_ - std::sin(a) * (14 + trail_), ty = y_ + std::cos(a) * (14 + trail_);
    float x0 = std::fmin(x_, tx), x1 = std::fmax(x_, tx), y0 = std::fmin(y_, ty), y1 = std::fmax(y_, ty);
    const int pad = 28;
    return Rect{int(x0) - pad, int(y0) - pad, int(x1 - x0) + 2 * pad, int(y1 - y0) + 2 * pad}.intersect(kBand);
}

void PlaneBand::update(float dt, DamageList& damage) {
    t_s_ += dt;
    if (full_) damage.add(kBand);
    full_ = false;
    int b = has_ ? int(bearing_ + 0.5f) : -1;
    if (b != shownBearing_) damage.add(kCompassBox), shownBearing_ = b;
    if (!has_) return;
    trail_ = std::fmin(kTrailMax, trail_ + kTrailMax / kTrailGrowS * dt);
    y_ = 66 + std::sin(t_s_ * 1.3f) * 1.5f;  // a gentle bob keeps it alive
    Rect r = box();
    damage.add(r.unite(last_));
    last_ = r;
}

void PlaneBand::draw(Canvas& c) {
    if (!has_ || !c.clip().intersects(kBand)) return;
    if (c.clip().intersects(box())) {
        float a = heading_ * kDeg, sx = -std::sin(a), sy = std::cos(a);
        // Contrail: segments widen and fade with distance behind the tail.
        const int kSeg = 10;
        for (int i = 0; i < kSeg; ++i) {
            float f0 = float(i) / kSeg, f1 = float(i + 1) / kSeg;
            float d0 = 14 + trail_ * f0, d1 = 14 + trail_ * f1;
            uint8_t al = uint8_t(150 * (1 - f0) * (1 - f0));
            aaLine(c, x_ + sx * d0, y_ + sy * d0, x_ + sx * d1, y_ + sy * d1, 1.8f + f0 * 4.f, t_.text, al);
        }
        c.radialGlow(x_, y_, 24, {255, 236, 200}, 110);
        planeGlyph(c, x_, y_, 34, heading_, t_.text);
    }
    if (c.clip().intersects(kCompassBox)) ui::compass(c, 212, 28, 16, bearing_, t_);
}

void InfoCard::build(Text& t) const {
    std::memset(&t, 0, sizeof t);
    if (!f_) {
        std::snprintf(t.callsign, sizeof t.callsign, "%s", "");
        std::snprintf(t.footer, sizeof t.footer, "%s", scene_ && !scene_->online ? "Offline" : "Scanning the sky…");
        return;
    }
    const SceneFlight& f = *f_;
    const SceneRoute* r = scene_ ? scene_->route(f.callsign) : nullptr;
    const data::Airline* al = data::airlineForCallsign(f.callsign);
    std::snprintf(t.callsign, sizeof t.callsign, "%s", f.callsign);
    std::snprintf(t.airline, sizeof t.airline, "%s", al ? al->name : r ? r->airline : (f.military ? "Military" : ""));
    const char* tn = data::aircraftTypeName(f.type);
    if (tn && std::strlen(tn) > 16) tn = nullptr;  // long names do not fit beside the callsign
    std::snprintf(t.typeLine, sizeof t.typeLine, "%s%s%s", tn ? tn : f.type, f.reg[0] ? " · " : "", f.reg);
    if (f.hasRoute) {
        std::snprintf(t.orig, sizeof t.orig, "%s", f.orig);
        std::snprintf(t.dest, sizeof t.dest, "%s", f.dest);
        if (f.progress >= 0 && f.etaEpoch) {
            char hm[8];
            ui::formatClock(hm, sizeof hm, f.etaEpoch);
            std::snprintf(t.progress, sizeof t.progress, "%d%% · lands ~%s", int(f.progress * 100 + 0.5f), hm);
        } else if (f.progress >= 0) {
            std::snprintf(t.progress, sizeof t.progress, "%d%%", int(f.progress * 100 + 0.5f));
        }
        if (r) {
            ui::ellipsize(t.origCity, sizeof t.origCity, kFontSmall, r->origCity, 100);
            ui::ellipsize(t.destCity, sizeof t.destCity, kFontSmall, r->destCity, 100);
        }
    }
    std::snprintf(t.tiles[0][0], 24, "ALT FT");
    ui::formatThousands(t.tiles[0][1], 24, f.altFt);
    ui::formatVrate(t.tiles[0][2], 24, f.vrateFpm);

void InfoCard::update(float, DamageList& damage) {
    build(text_);
    const Text& t = text_;
    uint32_t sig[4] = {
        ui::hashStr(t.callsign, ui::hashStr(t.airline, ui::hashStr(t.typeLine))),
        // The progress text changes with every whole percent, which also moves the bar.
        ui::hashStr(t.orig, ui::hashStr(t.dest, ui::hashStr(t.progress, ui::hashStr(t.origCity,
                    ui::hashStr(t.destCity, f_ && f_->hasRoute ? 1u : 2u))))),
        ui::hashBytes(t.tiles, sizeof t.tiles),
        ui::hashStr(t.footer),

}
```

```cpp
    const data::Airline* al = data::airlineForCallsign(f.callsign);
    const char* tn = data::aircraftTypeName(f.type);

void BoardList::sync(DamageList& damage) {
    dirty_ = false;
    for (auto& r : rows_) r.live = false;
    int n = scene_ ? (scene_->count < kRows ? scene_->count : kRows) : 0;
    for (int i = 0; i < n; ++i) {
        const SceneFlight& f = scene_->flights[i];
        float target = float(kFirstY + i * kPitch);
        Row* row = nullptr;
        for (auto& r : rows_)
            if (r.hex == f.hex) row = &r;
        if (!row) {
            for (auto& r : rows_)
                if (!r.hex) {
                    row = &r;
                    break;
                }
            if (!row) continue;
            *row = Row{};
            row->hex = f.hex, row->y = target;  // new rows appear in place and fade in
        }
        row->live = true, row->target = target;
        fill(*row, f, i == 0);
        uint32_t sig = ui::hashBytes(row->cs, sizeof row->cs + sizeof row->route + sizeof row->sub + sizeof row->dist +
                                                  sizeof row->alt) ^
                       uint32_t(row->first);
        if (sig != row->sig) damage.add(rowRect(row->y));
        row->sig = sig;
    }
    int count = scene_ ? scene_->count : 0;
    if ((count == 0) != (count_ == 0)) damage.add(kListArea);
    count_ = count;
    std::snprintf(header_, sizeof header_, count == 1 ? "%d flight" : "%d flights", count);
    if (scene_ && scene_->timeValid) ui::formatClock(clock_, sizeof clock_, scene_->epoch);
    else clock_[0] = 0;
}

uint32_t BoardList::hitTest(int, int y) const {
    for (const auto& r : rows_)
        if (r.hex && r.live && r.alpha > 0.5f && y >= r.y && y < r.y + kRowH) return r.hex;
    return 0;
}

void BoardList::update(float dt, DamageList& damage) {
    if (full_) damage.add(kListArea), damage.add(kHeaderText);
    full_ = false;
    if (dirty_) sync(damage);
    float k = std::fmin(1.f, dt * 12.f);  // ~0.3 s to settle
    for (auto& r : rows_) {
        if (!r.hex) continue;
        float y0 = r.y, a0 = r.alpha;
        r.y += (r.target - r.y) * k;
        if (std::fabs(r.target - r.y) < 0.3f) r.y = r.target;
        float da = dt / 0.3f;
        r.alpha = r.live ? std::fmin(1.f, r.alpha + da) : std::fmax(0.f, r.alpha - da);
        if (r.y != y0 || r.alpha != a0) damage.add(rowRect(y0).unite(rowRect(r.y)));
        if (!r.live && r.alpha <= 0) r.hex = 0;
    }
    uint32_t sig = ui::hashStr(header_, ui::hashStr(clock_));
    if (sig != headerSig_) damage.add(kHeaderText);
    headerSig_ = sig;
}
```

```cpp
gfx::Vec2 domeProject(float az, float elev, const DomeGeom& g) {
```

```cpp
#include <cmath>
#include <cstdio>
#include <cstring>

#include "ui/Format.h"

namespace scr {
using namespace gfx;

namespace {
constexpr float kPi = 3.14159265f;
// The treeline ellipse sits just outside the projection's horizon, so elevation 0 is
// hidden behind the trees, as it would be.
constexpr float kTreeRx = 116, kTreeRy = 136;

float wobble(float theta) {
    return 1.f + 0.05f * std::sin(theta * 9.f) + 0.03f * std::sin(theta * 23.f + 1.f) +
           0.02f * std::sin(theta * 41.f + 2.f);
}
}  // namespace

// ------------------------------------------------------------------ SkyDome

SkyDome::SkyDome(const Theme& t) : t_(t) {
    for (int y = 0; y < 320; ++y) {
        float dy = (y + 0.5f - g_.cy) / kTreeRy;
        if (std::fabs(dy) >= 1) {
            spanL_[y] = spanR_[y] = int16_t(g_.cx * 16);
            continue;
        }
        float hx = kTreeRx * std::sqrt(1 - dy * dy);
        float thR = std::atan2(dy, hx / kTreeRx), thL = kPi - thR;
        spanR_[y] = int16_t((g_.cx + hx * wobble(thR)) * 16);
        spanL_[y] = int16_t((g_.cx - hx * wobble(thL)) * 16);
    }
}

void SkyDome::setScene(const Scene* s) {
    scene_ = s;
    if (!s) return;
    bool moved = std::fabs(s->sunElev - sunElev_) > 0.25f || std::fabs(s->sunAz - sunAz_) > 0.5f ||
                 std::fabs(s->moonElev - moonElev_) > 0.25f || std::fabs(s->moonAz - moonAz_) > 0.5f ||
                 std::fabs(s->moonIllum - moonIllum_) > 0.01f;
    bool stale = s->timeValid && (s->epoch - starEpoch_ >= 60 || s->epoch < starEpoch_);
    if (moved || stale || full_) recompute();
}

void SkyDome::recompute() {
    const Scene& s = *scene_;
    sunElev_ = s.sunElev, sunAz_ = s.sunAz, moonElev_ = s.moonElev, moonAz_ = s.moonAz, moonIllum_ = s.moonIllum;
    nStars_ = 0;
    if (s.timeValid && s.locationSet) {
        starEpoch_ = s.epoch;
        for (int i = 0; i < data::kStarCount && nStars_ < kMaxStars; ++i) {
            const data::Star& st = data::kStars[i];
            svc::HorizPos h = svc::equatorialToHorizontal(st.raDeg, st.decDeg, s.epoch, s.homeLat, s.homeLon);
            if (h.elevationDeg < 4) continue;
            Vec2 p = domeProject(float(h.azimuthDeg), float(h.elevationDeg), g_);
            float a = 255.f - (st.mag + 1.5f) * 45.f;
            stars_[nStars_++] = {int16_t(p.x), int16_t(p.y), uint8_t(a < 70 ? 70 : a > 255 ? 255 : a),
                                 uint8_t(st.mag < 1.0f)};
        }
        std::sort(stars_, stars_ + nStars_, [](const StarPt& a, const StarPt& b) { return a.y < b.y; });
    }
    full_ = true;
}

void SkyDome::update(float, DamageList& damage) {
    if (full_) damage.addAll();
    full_ = false;
}

void SkyDome::drawTrees(Canvas& c) const {
    const Rect& cl = c.clip();
    uint16_t tree = rgb565(t_.tree);
    for (int y = cl.y; y < cl.bottom(); ++y) {
        float l = spanL_[y] / 16.f, r = spanR_[y] / 16.f;
        int il = int(std::floor(l)), ir = int(std::floor(r));
        for (int x = cl.x; x < cl.right(); ++x) {
            if (x < il || x > ir) c.at(x, y) = tree;
            else if (x == il) c.at(x, y) = blend565(c.at(x, y), tree, uint8_t(255 * (1 - (l - il))));
            else if (x == ir) c.at(x, y) = blend565(c.at(x, y), tree, uint8_t(255 * (r - ir)));
        }
    }
}

void SkyDome::draw(Canvas& c) {
    app::SkyStops ss = app::skyForSun(sunElev_);
    Rgb stops[] = {ss.top, ss.mid, ss.horizon};
    float pos[] = {0.f, 0.6f, 1.f};
    c.radialGradient({0, 0, 240, 320}, g_.cx, g_.cy, g_.rx * 1.1f, g_.ry * 1.1f, stops, pos, 3);

    if (sunElev_ > -12) {
        Vec2 p = domeProject(sunAz_, sunElev_ > 0 ? sunElev_ : 0, g_);
        uint8_t a = uint8_t(sunElev_ > 0 ? 170 : 170 * (sunElev_ + 12) / 12);
        c.radialGlow(p.x, p.y, 90, t_.sunGlow, a / 2);
        c.radialGlow(p.x, p.y, 28, t_.sunCore, a);
        if (sunElev_ > 0) aaCircle(c, p.x, p.y, 8, t_.sunDisc);
    }

    float starF = sunElev_ < -14 ? 1.f : sunElev_ < -6 ? (-6 - sunElev_) / 8.f : 0.f;
    if (starF > 0) {
        const Rect& cl = c.clip();
        StarPt key{0, int16_t(cl.y - 2), 0, 0};
        auto it = std::lower_bound(stars_, stars_ + nStars_, key, [](const StarPt& a, const StarPt& b) { return a.y < b.y; });
        for (; it != stars_ + nStars_ && it->y <= cl.bottom() + 1; ++it) {
            uint8_t a = uint8_t(it->a * starF);
            if (it->big) aaCircle(c, it->x + 0.5f, it->y + 0.5f, 1.1f, {255, 250, 240}, a);
            else c.blendPixel(it->x, it->y, {235, 240, 255}, a);
        }
    }

    if (moonElev_ > 0) {
        Vec2 p = domeProject(moonAz_, moonElev_, g_);
        const float r = 7;
        c.radialGlow(p.x, p.y, 30, t_.moonGlow, 70);
        aaCircle(c, p.x, p.y, r, t_.moon);
        if (moonIllum_ < 0.97f) {
            // The dark part faces away from the sun: a sky-coloured disc offset from the moon.
            Vec2 s = domeProject(sunAz_, 0, g_);
            float vx = s.x - p.x, vy = s.y - p.y, len = std::sqrt(vx * vx + vy * vy);
            if (len < 1) len = 1;
            float off = 2 * r * moonIllum_;
            float qx = (p.x - g_.cx) / (g_.rx * 1.1f), qy = (p.y - g_.cy) / (g_.ry * 1.1f);
            Rgb sky = sampleStops(stops, pos, 3, std::sqrt(qx * qx + qy * qy));
            aaCircle(c, p.x - vx / len * off, p.y - vy / len * off, r + 0.4f, sky);
        }
    }
    drawTrees(c);

Rect SkyPlanes::boxFor(const Track& k) const {
    float x0 = k.pos.x, x1 = k.pos.x, y0 = k.pos.y, y1 = k.pos.y;
    for (int i = 0; i < k.n; ++i) {
        x0 = std::fmin(x0, k.pts[i].x), x1 = std::fmax(x1, k.pts[i].x);
        y0 = std::fmin(y0, k.pts[i].y), y1 = std::fmax(y1, k.pts[i].y);
    }
    int pad = int(k.size) + 8;
    return {int(x0) - pad, int(y0) - pad, int(x1 - x0) + 2 * pad, int(y1 - y0) + 2 * pad};
}

void SkyPlanes::sync(DamageList& damage) {
    dirty_ = false;
    for (auto& k : tracks_) k.live = false;
    int used = 0;
    for (int i = 0; scene_ && i < scene_->count && used < kMaxTracks; ++i) {
        const SceneFlight& f = scene_->flights[i];
        if (f.elevDeg < 2) continue;  // behind the trees
        ++used;
        Track* k = nullptr;
        for (auto& t : tracks_)
            if (t.hex == f.hex) k = &t;
        if (!k) {
            for (auto& t : tracks_)
                if (!t.hex) {
                    k = &t;
                    break;
                }
            if (!k) break;
            *k = Track{};
            k->hex = f.hex, k->sampleT = t_s_;
        }
        k->live = true;
        k->pos = domeProject(f.bearingDeg, f.elevDeg);
        k->heading = 360.f - f.trackDeg;  // mirrored: we are looking up
        float sz = 24.f - f.distNm * 1.4f;
        k->size = sz < 9 ? 9 : sz > 22 ? 22 : sz;
    }
    for (auto& k : tracks_) {
        if (!k.hex) continue;
        Rect b = k.live ? boxFor(k) : Rect{};
        if (k.box.x != b.x || k.box.y != b.y || k.box.w != b.w || k.box.h != b.h) damage.add(k.box.unite(b));
        k.box = b;
        if (!k.live) k.hex = 0;
    }
}

void SkyPlanes::update(float dt, DamageList& damage) {
    t_s_ += dt;
    if (dirty_) sync(damage);
    for (auto& k : tracks_) {
        if (!k.hex || t_s_ - k.sampleT < 1.f) continue;
        k.sampleT = t_s_;
        for (int i = (k.n < kTrail ? k.n : kTrail - 1); i > 0; --i) k.pts[i] = k.pts[i - 1];
        k.pts[0] = k.pos;
        if (k.n < kTrail) ++k.n;
        Rect b = boxFor(k);
        damage.add(k.box.unite(b));
        k.box = b;
    }
    bool on = std::fmod(t_s_, 1.f) < 0.15f;
    if (on != beaconOn_)
        for (auto& k : tracks_)
            if (k.hex) damage.add({int(k.pos.x) - 8, int(k.pos.y) - 8, 17, 17});
    beaconOn_ = on;
}

void SkyPlanes::draw(Canvas& c) {
    for (const auto& k : tracks_) {
        if (!k.hex || !c.clip().intersects(k.box)) continue;
        Vec2 prev = k.pos;
        for (int i = 0; i < k.n; ++i) {
```

```cpp
// Chooses the screen when nobody is touching the device. Rules (spec §4), in order: a
// close, low plane → Closest Flight; a plane high overhead when the sky is interesting →
// Sky View; planes in range → Radar and Board alternating; nothing → Sky View; no location
// or clock → Radar. A screen stays at least 20 s, thresholds release 20 % past where they
// trigger, and a touch hands control to the user for a minute.
#include "Scene.h"
#include "Screen.h"

namespace scr {

enum class DirectorMode : uint8_t { Auto, Carousel, Stay };

class Director {
   public:
    static constexpr uint32_t kDwellMs = 20000, kExploreMs = 60000, kAlternateMs = 45000;
    static constexpr float kCloseNm = 3, kCloseFt = 15000, kHighDeg = 45, kRelease = 1.2f;

    void configure(DirectorMode mode, uint32_t carouselMs) { mode_ = mode, carouselMs_ = carouselMs; }
    void noteTouch(uint32_t now) { lastTouch_ = now, touched_ = true; }
    bool exploring(uint32_t now) const { return touched_ && now - lastTouch_ < kExploreMs; }
    // The screen that should be showing now; `current` is what the host shows.
    ScreenId decide(const Scene& s, ScreenId current, uint32_t now);

   private:
    ScreenId rule(const Scene& s, uint32_t now);
    DirectorMode mode_ = DirectorMode::Auto;
    uint32_t carouselMs_ = 30000;
    bool started_ = false;
    // What we last asked for. Holding it (not the host's current screen) keeps a switch
    // going while the host is still fading out of the old screen.
    ScreenId asked_ = ScreenId::Count;
    uint32_t shownSince_ = 0;  // when we last asked for a different screen
    bool closeLatched_ = false, skyLatched_ = false, alternating_ = false;
    ScreenId alt_ = ScreenId::Radar;
    uint32_t altSince_ = 0;
    uint32_t lastTouch_ = 0;
    bool touched_ = false;
};
```

```cpp
#include "Director.h"

namespace scr {

namespace {
const ScreenId kCycle[] = {ScreenId::Closest, ScreenId::Radar, ScreenId::Board, ScreenId::Sky};
}

ScreenId Director::rule(const Scene& s, uint32_t now) {
    if (!s.locationSet || !s.timeValid) return alternating_ = false, ScreenId::Radar;
    if (s.count == 0) return closeLatched_ = skyLatched_ = alternating_ = false, ScreenId::Sky;
    float closeNm = closeLatched_ ? kCloseNm * kRelease : kCloseNm;
    float closeFt = closeLatched_ ? kCloseFt * kRelease : kCloseFt;
    float highDeg = skyLatched_ ? kHighDeg / kRelease : kHighDeg;
    bool close = false, high = false;
    for (int i = 0; i < s.count; ++i) {
        const SceneFlight& f = s.flights[i];
        if (f.distNm <= closeNm && f.altFt <= closeFt) close = true;
        if (f.elevDeg >= highDeg) high = true;
    }
    bool interesting = s.sunElev < 6 || s.moonElev > 0;
    closeLatched_ = close, skyLatched_ = high && interesting;
    if (close) return alternating_ = false, ScreenId::Closest;
    if (skyLatched_) return alternating_ = false, ScreenId::Sky;
    if (!alternating_) alternating_ = true, alt_ = ScreenId::Radar, altSince_ = now;
    else if (now - altSince_ >= kAlternateMs) alt_ = alt_ == ScreenId::Radar ? ScreenId::Board : ScreenId::Radar, altSince_ = now;
    return alt_;
}

ScreenId Director::decide(const Scene& s, ScreenId current, uint32_t now) {
    // The user is in charge: follow whatever they chose.
    if (mode_ == DirectorMode::Stay || exploring(now)) return asked_ = current;
    if (!started_) {  // the first decision after boot applies at once
        started_ = true, shownSince_ = now;
        return asked_ = mode_ == DirectorMode::Carousel ? current : rule(s, now);
    }
    ScreenId hold = asked_, want = hold;
    if (mode_ == DirectorMode::Carousel) {
        if (now - shownSince_ < carouselMs_) return hold;
        for (int i = 0; i < 4; ++i)
            if (kCycle[i] == hold) want = kCycle[(i + 1) % 4];
    } else {
        want = rule(s, now);
        if (want != hold && now - shownSince_ < kDwellMs) return hold;
    }
    if (want != hold) shownSince_ = now;
    return asked_ = want;
}

}  // namespace scr
```

```cpp
    for (int i = 0; i < kFrames; ++i) {

    }
    uint32_t avg = (micros() - t0) / kFrames;

}
```
