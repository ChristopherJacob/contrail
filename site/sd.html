SD card

Make a microSD card with the detailed Live Map for your home and real airline logos. It's all built here in the browser. Your exact location stays on this computer; the page downloads only the map data for your part of the world.

1. Where is home?

    2. Build

    Download contrail-sd-card.zip

    This page needs a browser with Web Workers and WebAssembly, such as a current Chrome, Edge, Firefox or Safari.

    3. Put it on the card

    1. Use a FAT32 microSD card. Most cards up to 32 GB come that way. Bigger cards are usually exFAT, which the board can't read: format them as FAT32 first (FAT16 works too).
    2. Unzip contrail-sd-card.zip onto the card, so the card has a contrail folder at the top holding map.pak and logos.pak.
    3. Put the card in the board and restart it. The Live Map draws the detailed map while home and the radius lie inside the map's 250 nm; the Firmware card on the board's web page says which map it uses.
    4. Moved house? Build the card again for the new home.

    Prefer the command line? tools/build_map.py in the repository makes the same map.
